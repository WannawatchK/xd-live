Signal: "±2 g" shows the acceleration itself in g (Z sits near +1 g because of gravity); "Zoom (mg)" applies a zero-phase 0.2 Hz high-pass (removes gravity, drift and slow tilt) and zooms in to see small vibrations. Long ranges show the min–max band of each pixel plus the mean line, so short shocks stay visible. Spectrum: Welch average over the whole range (65 s pieces = 0.015 Hz resolution, linear detrend, Hann window, half overlap) in µg/√Hz; dashed line = ADXL355 datasheet noise 22.5 µg/√Hz; "Spectrum linear" shows peaks the way single-FFT plots do (tall peaks, floor flattened near zero); "Spectrum log" keeps weak modes and the noise floor visible; dotted line = 15 Hz, top of the mode search band (the chip's own filter cuts off near 15.6 Hz). Labels = up to 5 peaks in 0.3–15 Hz at least 3× above the local floor, refined between bins. A peak is a candidate mode: check it shows on every node and stays put across recordings. Start / Stop: Start analyses only data from that moment (older data stays stored, just ignored); Stop freezes the window so you can read the result; Auto-stop stops by itself after the chosen time; All data goes back to the normal time range. While a window is set, the range buttons are ignored. The first 65 s use 16 s spectrum pieces (0.06 Hz), then 65 s pieces (0.015 Hz). The window is kept per node across reloads. Save CSV: saves exactly the samples in view (the Start→Stop window, or the selected time range) in the same layout as the step 3/5 lab files (raw LSB x,y,z with #T timing lines), so step3_noise.py and step5_shaker.py read it unchanged. Type a name such as step5_f5_v0.1 so step5_shaker.py knows the frequency and Vpp; empty = node + time. LIVE: while this page is open it asks the node to also send its newest samples every 0.25 s (about 0.5–1 s behind); the 10-second blocks fill in the history. Blocks are kept in this browser after the first download (one day of one node ≈ 86 MB). Times are Thailand time.
